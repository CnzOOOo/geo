## 核心方法论

### 1. AI 选择答案的四把尺

来自 `003`：

- 权威性：政府、专家、媒体、奖项、数据来源比个人自夸更可信。
- 结构化：编号、表格、FAQ、明确标题比长篇流水账更容易被提取。
- 匹配度：页面标题和正文要直接匹配用户完整提问。
- 新鲜度：保持规律更新，旧内容要定期翻新。

### 2. 内容生产公式

来自 `004` 到 `008`：

```text
用户完整提问 -> 三段式文章 -> 三类标题 -> 自然藏词 -> AI 初稿 -> 人工 E-E-A-T 审核
```

商家模板：

- 怎么做：`XX市XX区 怎么选一家靠谱的XX店`
- 哪个好：`XX和XX 哪个更适合家庭/新手/预算有限的人`
- 对比类：`XX店 和 XX店 在价格/服务/体验上差别大吗`
- 避坑类：`在XX市 找XX服务/买XX商品 要注意哪些坑`

### 3. 技术配置

来自 `009`、`010`：

- `robots.txt`：继续保留，解决传统搜索引擎基础收录。
- `llms.txt`：补充给 AI 模型看的公开内容清单，官网根目录配置。
- `sitemap.xml`：带 `lastmod`、`priority`，让 AI 知道哪些页面最新、最重要。
- JSON-LD：
  - 实体店：`LocalBusiness`
  - 商品：`Product` + `AggregateOffer`
  - 评价：真实 `Review`/`AggregateRating`
  - 问答：`FAQPage`
  - 文章：`Article`
- 结构化数据必须和页面正文一致，不能只为了“骗 AI”添加。

### 4. 分发闭环

来自 `011`、`012`：

```text
第一层 立权：官网/官方公众号/行业媒体发布 3000 字以上深度长文
第二层 扩声：拆成知乎问答、小红书图文、抖音短视频、行业媒体数据稿
第三层 埋点：评论区专业答疑、百科词条、PDF/PPT 文档、行业论坛
```

对店家来说，第三层要特别谨慎：必须用真实商家身份、真实内容，不能做假评论、假百科词条或批量机器人互动。

### 5. 效果监测

来自 `013`（实际内容）和 `015`：

- 收录：百度/Bing 搜索完整问题、标题、URL，确认内容是否被索引。
- 曝光：DeepSeek、豆包、ChatGPT 中是否出现品牌名、店铺名、链接。
- 转化：官网、平台后台是否出现高精准短停留流量、私信、到店、订单。

建议按周记录：

| 查询 | 引擎 | 是否收录 | 是否被引用 | 引用来源 | 是否准确 | 是否带来转化 |
|---|---|---|---|---|---|---|
| 示例问题 | DeepSeek | 是/否 | 是/否 | 官网/知乎/小红书 | 对/错 | 是/否 |

### 6. 组织与行业

来自 `016` 到 `021`：

- SEO 老资产不要删，关键词库升级为自然语言问题，老文章按三段式和 E-E-A-T 改造。
- 内容生产必须建立真实问题库，AI 只负责初稿，人工负责事实、案例、发布。
- 团队最小配置：项目负责人、技术优化、内容策略、数据分析。
- 本地生活商家的核心打法：区域精准问答 + 真人案例 + 避坑指南。
- 未来 AI Agent 会直接执行订单，因此公开知识库要提前做好。

## 对“店家搜索排名”的实战组合拳

```text
1. 建问题库：城市 + 区域 + 品类 + 怎么做/哪家好/对比/避坑
2. 建知识库：地址、营业时间、电话、服务、价格、资质、真实案例、FAQ
3. 产内容：三段式 + E-E-A-T + 三类标题 + 自然语言问题
4. 做技术：官网 llms.txt + sitemap + LocalBusiness/FAQ/Product 结构化数据
5. 做分发：官网首发，知乎/小红书/抖音/地图/点评按平台改写
6. 做监测：每周记录 AI 是否收录、引用、说对、带转化
7. 做迭代：旧文章补新数据、新案例，重新发布并复测
8. 做实验：同城商家分批上线，对比 mention rate、citation rate、准确率
```

## 不投毒和合规护栏

- 不伪造评价、销量、资质、媒体报道、专家背书。
- 不编造数据，不引用课程中没有出处的行业数据。
- 不用隐藏文字、关键词堆砌、门页、跳转页。
- 不在页面埋 prompt injection 诱导 AI 回答。
- 结构化数据必须与页面正文一致。
- 评论区、百科、PDF 分发必须使用真实身份和真实内容，不做假互动、假词条、假文档。
- AI Agent 知识库只能公开可验证的信息，不能把未公开、未授权的内部资料直接外发。
