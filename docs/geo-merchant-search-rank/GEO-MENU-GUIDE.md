## 1. 登录后台

1. 打开管理员提供的 GEO 后台地址。
2. 输入账号和密码。
3. 登录后，左侧菜单找到 `GEO运营`。
4. 先点开 `商家主档`。

> 如果看不到 GEO 菜单，说明当前账号没有 GEO 菜单权限，需要管理员在权限管理中分配。

## 2. 商家主档：先建商家

菜单路径：`GEO运营 -> 商家主档`

### 操作步骤

1. 点击右上角 `新增`。
2. 填写商家名称，例如 `上海 XX 咖啡`。
3. 选择行业类目。
4. 填写城市、区、详细地址。
5. 填写电话和营业时间。
6. 有官网、小程序、Logo 的尽量补充。
7. 点击保存。
8. 确认信息无误后，把状态改成 `启用`。

## 3. 问题库：记录用户会问什么

菜单路径：`GEO运营 -> 问题库`

### 操作步骤

1. 点击 `新增`。
2. 选择商家。
3. 填写完整自然语言问题。
4. 选择问题类型。
5. 填写用户意图，例如“找店”“比价”“避坑”。
6. 填写地域，例如“上海/徐汇区”。
7. 设置优先级。
8. 保存后保持 `启用`。

### 问题类型示例

| 类型 | 示例 |
|---|---|
| BRAND 品牌词 | XX咖啡 怎么样 |
| HOW 怎么做/是否 | XX咖啡 可以停车吗 |
| WHICH 推荐 | 徐汇区 适合办公的咖啡店 |
| COMPARE 对比 | XX咖啡 和 YY咖啡 哪个好 |
| AVOID 避坑 | 徐汇区 咖啡店 踩雷 |
| FAQ 常见问题 | XX咖啡 营业到几点 |

> 小白建议：第一批先录入 20 条，每条问题都必须是用户真实会搜索的话。

## 4. 知识库：维护真实事实

菜单路径：`GEO运营 -> 知识库`

### 操作步骤

1. 点击 `新增`。
2. 选择商家。
3. 填写“事实名”，例如 `营业时间`。
4. 填写“事实值”，例如 `周一至周五 09:00-21:00`。
5. 填写“来源”，例如官网、地图、点评。
6. 填写“验证时间”。
7. 保存后状态选择 `已验证`。

## 5. 文章工坊：生成内容

菜单路径：`GEO运营 -> 文章工坊`

### 操作步骤

1. 点击 `新增`。
2. 选择商家。
3. 选择要覆盖的问题。
4. 填写标题。
5. 填写摘要。
6. 在正文中写入 Markdown 内容。
7. 保存为草稿。
8. 点击 `提交审核`。
9. 审核通过后，才能发布到平台。

### 文章状态

| 状态 | 说明 | 下一步 |
|---|---|---|
| 0 草稿 | 还没提交 | 提交审核 |
| 1 待审核 | 等待人工确认 | 审核通过 |
| 2 已发布 | 可以进入发布任务 | 发布到草稿箱 |
| 3 已下线 | 不再使用 | 可重新编辑 |

## 6. 发布渠道：配置平台

菜单路径：`GEO运营 -> 发布渠道`

### 操作步骤

1. 点击 `新增`。
2. 选择商家。
3. 选择平台，例如知乎、B站、CSDN、简书。
4. 填写渠道名称，例如 `知乎-主账号`。
5. 开启 Wechatsync 桥接。
6. 配置 Token 和端口：

```json
{
  "wechatsyncEnabled": true,
  "token": "Chrome 扩展中的 Token",
  "wsPort": "9527"
}
```

7. 保存后，渠道状态保持 `启用`。

## 7. 发布任务：创建草稿

菜单路径：`GEO运营 -> 发布任务`

### 操作步骤

1. 点击 `新增`。
2. 选择文章。
3. 选择渠道。
4. 保存任务。
5. 点击 `创建并执行`。
6. 等待执行结果。
7. 成功后，在任务记录里复制外部草稿链接。

## 8. Wechatsync 环境检查

菜单路径：`GEO运营 -> Wechatsync 环境检查`

### 发布前必须确认

| 检查项 | 正常状态 |
|---|---|
| CLI 已安装 | 是 |
| CLI 路径 | 有实际路径 |
| Token 已配置 | 是 |
| WebSocket 端口 | 9527 |
| Chrome 扩展同步桥接 | 已连接 |
| 平台登录 | 知乎、CSDN、简书等已登录 |

### 操作步骤

1. 点击 `重新检测`，确认 CLI 状态。
2. 点击 `打开扩展设置`。
3. 在 Chrome 扩展中开启 `CLI / MCP 连接`。
4. 复制扩展中的 Token。
5. 回到 GEO，点击 `检查平台登录`。
6. 看到 `Chrome Extension 已连接` 后再发布。

## 9. AI 回答监测

菜单路径：`GEO运营 -> 监测任务 / AI 回答`

### 操作步骤

1. 在监测任务中点击 `新增`。
2. 选择商家。
3. 填写查询集：

```json
[
  { "query": "上海 咖啡店 推荐" },
  { "query": "XX咖啡 怎么样" }
]
```

4. 配置执行周期。
5. 点击 `立即执行`。
6. 到 AI 回答列表查看结果。

### 重点检查

- AI 是否提到了商家
- 地址、电话、营业时间是否正确
- 引用来源是否真实
- 回答情绪是正面、中性还是负面

## 常见问题

### 看不到 GEO 菜单

检查当前账号是否已分配 GEO 菜单权限。

### 发布任务失败：需要安装 Chrome 扩展

在 Wechatsync 环境检查页点击“打开扩展设置”，并开启 `CLI / MCP 连接`。

### 发布任务失败：请先登录平台

用 Chrome 打开目标平台并登录，再回到 GEO 点击“检查平台登录”。

### 发布任务失败：用户不通过

通常是平台账号资质未通过，需要到平台后台确认账号状态。

### AI 监测没有结果

确认已配置 AI Key；未配置时，系统会生成 `MANUAL_REVIEW_REQUIRED`，需要人工补录。

## 注意事项

- 所有内容必须基于真实事实。
- 不编造评价、不诱导 AI、不制作虚假背书。
- 发布任务默认只创建草稿，确认无误后再正式发布。
- 遇到事实变化，先更新知识库，再处理相关文章和舆情。
