# GEO 商家数据提交清单

## 1. 商家主档（必填）

以下数据用于创建 `geo_merchant`，也是知识库、SEO、文章和发布任务的公共基础。

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| 商家名称 | 是 | 营业执照/平台使用的正式名称 | 上海 XX 咖啡 |
| 常用别名 | 建议 | 用户搜索时可能叫的名字 | XX咖啡、XXCoffee |
| 行业类目 | 是 | 主类目 | 咖啡店 / 餐饮 / 美容美发 |
| 省 | 是 | 运营区域 | 上海 |
| 市 | 是 | 运营城市 | 上海市 |
| 区 | 是 | 主要服务区 | 徐汇区 |
| 详细地址 | 是 | 精确到门牌 | 上海市徐汇区XX路100号 |
| 经度 | 建议 | 地图坐标，可从高德/百度获取 | 121.4377 |
| 纬度 | 建议 | 地图坐标 | 31.1923 |
| 联系电话 | 是 | 官方客服电话 | 021-12345678 |
| 营业时间 | 是 | 建议每周完整格式 | 周一至周五 09:00-21:00；周六日 10:00-22:00 |
| 服务范围 | 建议 | 可服务的区域 | 徐汇、静安、黄浦 |
| 官网 | 建议 | 自有域名 | https://www.example.com |
| 小程序 | 建议 | 微信小程序名/链接 | XXCoffee |
| Logo | 建议 | 高清图，建议 PNG | logo.png |
| 一句话简介 | 是 | 用于摘要和文章开头 | 主打精品手冲和本地烘焙的社区咖啡店 |

## 2. 问题库（第一批建议 20-50 条）

用于 `geo_question_bank`，覆盖真实用户搜索问题。

| 问题类型 | 示例 |
|---|---|
| BRAND 品牌词 | XX咖啡 怎么样 |
| HOW 怎么做/是否 | XX咖啡 可以停车吗 |
| WHICH 推荐 | 徐汇区 适合办公的咖啡店 |
| COMPARE 对比 | XX咖啡 和 YY咖啡 哪个好 |
| AVOID 避坑 | 徐汇区 咖啡店 踩雷 |
| FAQ 常见问题 | XX咖啡 营业到几点、有无插座、能否带宠物 |

每条问题建议提供：

- 完整自然语言问题
- 用户意图：找店、比价、预约、避坑、营业信息
- 地域：上海/徐汇区
- 优先级：1-5
- 来源：搜索词、评价、客服记录、平台问答

## 3. 知识库（第一批建议 30-80 条）

用于 `geo_knowledge_item`，每条是“事实名 + 事实值 + 来源”。

### 3.1 基础事实

- 地址、电话、营业时间、休息日
- 主营产品/服务
- 价格区间、起步价、套餐
- 停车、地铁、公交路线
- 预约方式、排队情况、是否支持外卖
- 会员、积分、优惠活动
- 门店照片、宣传片

### 3.2 可信证据

- 营业执照名称和经营范围
- 资质证书、卫生等级、认证
- 获奖、媒体报道、行业榜单
- 地图平台 POI 链接
- 大众点评/美团/小红书/抖音主页
- 官网、公众号、视频号
- 创始人/主理人介绍、团队背景

### 3.3 差异化事实

- 独特工艺、独家产品
- 本地供应商
- 特色服务：宠物友好、儿童区、会议室
- 适合场景：办公、约会、亲子、聚会

## 4. 文章素材（第一批建议 3-5 篇）

用于 `geo_article` 草稿生成和发布测试。

建议提供：

- 目标问题：例如“徐汇区适合办公的咖啡店”
- 标题方向
- 文章主题和核心观点
- 真实体验/采访/照片
- 商家真实数据和引用来源
- 希望覆盖的平台：知乎、CSDN、简书、公众号、百家号、头条等

注意：文章只做真实内容建设，不编造评价、不诱导 AI、不制造虚假背书。
